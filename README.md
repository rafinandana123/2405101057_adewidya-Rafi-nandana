## Cara Menjalankan Aplikasi

1. Clone atau download repository ini.
2. Buka folder modul yang ingin dijalankan.
3. Buka source code menggunakan aplikasi atau IDE yang sesuai dengan teknologi yang digunakan.
4. Jalankan aplikasi sesuai dengan teknologi yang digunakan pada modul praktikum.
5. Untuk melihat screenshot hasil praktikum, buka folder `screenshot` di dalam folder modul terkait.
